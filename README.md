## 📖 About

InternHub Backend powers the core functionality of the InternHub platform. It manages users, internships, applications, and authentication, enabling students to easily find and apply for internship opportunities.

The system is designed with scalability in mind using a clean **Controller-Model-Route** architecture, making it easy to extend and maintain.

---

## 🛠 Tech Stack

- **Runtime**: Node.js  
- **Language**: TypeScript  
- **Framework**: Express.js  
- **Database**: SQLite (Development) / Drizzle ORM
- **Authentication**: JSON Web Tokens (JWT) & bcryptjs  
- **Validation**: TypeScript + custom middleware
